How to Play

  • Pick a study mode, then design your explorer.
  • Your explorer auto-runs through the jungle.
  • A wild animal blocks the path — a vocab question appears.
  • Two answer bubbles appear at the bottom. Tap or press ← → to answer.
  • Correct ✅ — the animal flees and you keep running!
  • Wrong ❌ — lose a ❤️ heart, the animal stays briefly then you keep going.
  • Answer all 15 encounters and reach the treasure to win!
  • Score 80%+ (12/15) for victory. Chain answers for 🔥 streak bonus points!

🌿 Behind the Build
How I Built Diction Dash

🎮 Canvas Game Engine

The game runs on an HTML5 <canvas> with a 60fps requestAnimationFrame loop. A parallax world scrolls five independent layers — sky, far trees, mid canopy, ground foliage, and a dirt path — each at different scroll speeds to create real depth. No external game engine is used.

🧑 Drawn Character

The explorer is drawn entirely with canvas 2D API calls — no sprites. A rounded head, two-tone body with outfit color, arms that swing via sine-wave animation, legs that stride left/right alternately, feet, and a hair style layered on top. The same draw function renders the title screen preview, HUD mini-portrait, and in-game character. Skin tone, outfit color, and hair style are fully customizable.

🦁 Animal Blocking Mechanic

When the runner reaches an encounter trigger, the game enters ENCOUNTER state. A large animal is drawn on-canvas center-path, bouncing with a sinusoidal idle animation. The question banner drops from the top, and two answer bubbles slide up from the bottom. The animal has a rage shake on a wrong answer and a flee animation (slides off-screen right) on a correct one. The runner slows to a halt as it approaches the animal, then resumes after the answer.

📚 Vocab & Randomization

16 coding words (term, definition, analogy, example). Each round draws 15 via Fisher-Yates shuffle, assigns a question type per slot, and pulls 1 wrong answer from the remaining pool. Correct/wrong sides are randomized 50/50 each encounter.

🏆 Scoring & Win

80%+ = WIN. +10 pts per correct. Streak ×2 at 3 in a row, ×3 at 5. 3 hearts; wrong answers cost 1 heart. Letter grades A+–F on the results screen with a personalised story message.

📱 Touch + Keyboard

Answer bubbles are large tap targets for mobile. Keyboard ← → also works. The canvas and all HUD elements use vw/vh and clamp() sizing so the game fills any screen size without scrolling.
